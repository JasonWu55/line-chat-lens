Export Guide

如何從 Telegram 匯出對話 JSON

建議使用 Telegram Desktop。這個分析頁需要的是匯出的 result.json，不是純文字或 HTML。

Step 1

打開聊天右上角選單

進入你要分析的單一對話，打開右上角的 More 選單，選擇 Export chat history。

Step 2

格式選 JSON 後匯出

在匯出視窗把格式設成 JSON，時間範圍可選完整對話。若你只想分析文字， 媒體項目可以不勾選，檔案會更小。匯出完成後，把資料夾裡的 result.json 拖進這個頁面即可。

Timeline

月度訊息趨勢

依月份聚合，適合長期對話觀察。

Rhythm

每週時段熱區

看雙方通常在哪些時段互動。

Cadence

回覆速度分布

看這段對話通常隔多久會輪到另一方接話。

這張圖看的不是單一訊息有沒有被精準回覆，而是對話在雙方輪流發言時，通常會隔多久。 例如 A 說完後換 B 出聲，這段間隔就會被算進來；如果同一個人連續傳很多則，會視為同一波發話。 目前不會排除長時間沉默，超過 3 天的間隔會直接落在「>3d」這一格。

Density

Language

Phrases

Format
