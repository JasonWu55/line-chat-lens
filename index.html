Export Guide

如何從 Telegram 匯出對話 JSON

建議使用 Telegram Desktop。這個分析頁需要的是匯出的 result.json，不是純文字或 HTML。

Step 1

開啟聊天右上角選單

進入你要分析的單一對話，開啟右上角的 More 選單，選擇 Export chat history。

Step 2

格式選 JSON 後匯出

在匯出視窗把格式設成 JSON，時間範圍可選完整對話。若你只想分析文字， 媒體項目可以不勾選，檔案會更小。匯出完成後，把資料夾裡的 result.json 拖進這個頁面即可。

Insights

關係洞察

先用三張高訊號卡片快速抓出這段對話的節奏、波動與雙向互動差異。

Rhythm

每週時段熱區

看雙方通常在哪些時段互動。

Cadence

回覆速度分布

前段用秒級細分，後段合併成分鐘、小時與天級區間，看回覆節奏更清楚。

這張圖看的不是單一訊息有沒有被精準回覆，而是對話在雙方輪流發言時，通常會隔多久。 例如 A 說完後換 B 出聲，這段間隔就會被算進來；如果同一個人連續傳很多則，會視為同一波發話。 目前區間為 0-5s、5-20s、20-60s、1-5m、5-30m、30m-6h、6h-1d、>1d。 這樣可以把大量即時來回的訊號拆開，同時避免長尾區間過碎而難以判讀。

Daily Pulse

日度訊息趨勢

先看日級波動，辨認這段關係是穩定往來還是偶發爆量。

Timeline

月度訊息趨勢

把波動拉長到月份尺度，觀察整段對話的熱度起伏。

Density

熱門活躍日期

找出訊息量異常集中的日子。

Format

雙方訊息樣態比例

比較每位參與者常用哪些訊息形式，輔助判讀互動風格。

Phrases

雙方愛用詞彙與口頭禪

拆分每位參與者，優先看更有個性辨識度的短句與口頭禪。

Signals

互動訊號

補充編輯、轉傳、連結與收到反應，讓互動風格不只剩字數與頻率。

Reactions

反應分布

統計整段對話裡最常出現的表情反應，也把自訂表情另外歸類。

People

參與者比較

訊息量、字數、媒體比例，以及編輯、轉傳、連結與收到反應。

Language

常見語詞線索

以精確詞頻搭配候選詞切分整理，中文長句仍可能混入片段詞，適合當輔助線索。

Calls

通話互動分析

從 Telegram 匯出裡的電話事件整理通話頻率、時長與時段。
